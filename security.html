SECURITY / RESPONSIBLE DISCLOSURE

Security is a
continuous practice.

This portfolio is designed with a defense-in-depth mindset. No internet-connected system can be guaranteed completely secure; controls and dependencies should be reviewed and improved over time.

01 / PHILOSOPHY

Reduce common risks

Use established security practices, limit unnecessary data collection, and keep public information separate from private systems.

02 / PRIVACY

Respect visitor data

This static portfolio does not provide visitor accounts or intentionally collect personal data. Contact is handled through LinkedIn.

03 / ABUSE PREVENTION

Keep access appropriate

Public pages are intended for normal browsing. Automated abuse protections may be provided by the site host or upstream services.

04 / DISCLOSURE

Report responsibly

If you believe you have found a security issue, share a concise description and steps to reproduce it. Avoid accessing or changing other people’s data.
